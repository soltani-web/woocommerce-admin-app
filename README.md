# اپلیکیشن موبایل مدیریت فروشگاه ووکامرس + سامانه اختصاصی فروش و لایسنس

یک سیستم کامل و تجاری شامل **اپلیکیشن موبایل مدرن و سبک (React Native / Expo / TypeScript)** با رابط کاربری کاملاً **فارسی و راست‌چین (RTL)** برای مدیریت فروشگاه‌های ووکامرس، به همراه **سامانه اختصاصی هاست، فروش پلن‌ها و درگاه پرداخت آنلاین زیبال (Zibal)** بدون وابستگی به سرویس‌های خارجی.

---

## ✨ بخش‌های اصلی پروژه

### ۱. اپلیکیشن موبایل ادمین ووکامرس (Mobile App)
* **مدیریت چندفروشگاهی (Multi-Store):** افزودن بینهایت فروشگاه و سوییچ آنی بین آن‌ها بدون نیاز به خروج.
* **داشبورد تحلیلی:** نمایش آمار فروش ۳۰ روزه، درآمد خالص، وضعیت سفارشات در انتظار و کالاهای ناموجود.
* **مدیریت سفارش‌ها:** جستجوی هوشمند بر اساس شماره سفارش، نام و موبایل خریدار، تغییر آنی وضعیت سفارش، ثبت یادداشت و تماس مستقیم با مشتری.
* **مدیریت محصولات و انبارداری:** ویرایش سریع (Quick Edit) قیمت عادی، قیمت حراج و موجودی کالاها و مدیریت محصولات متغیر.
* **سیستم امنیتی لایسنس:** قفل سخت‌افزاری به شناسه دستگاه (Device ID Binding) و اعتبارسنجی آنلاین با سرور اختصاصی.

### ۲. سرور اختصاصی لایسنس و درگاه زیبال (`/license-server`)
* **صفحه لندینگ مدرن و لوکس:** طراحی شیک Dark/Glassmorphism با Tailwind CSS و فونت وزیرمتن جهت نمایش پلن‌ها و تعرفه‌ها.
* **اتصال به درگاه پرداخت زیبال:** پرداخت آنلاین امن و ریالی/تومانی.
* **تحویل آنی لایسنس و فایل APK:** صدور خودکار کد لایسنس به همراه دکمه کپی و لینک دانلود مستقیم پس از پرداخت موفق.
* **پنل مدیریت ادمین:**
  * داشبورد آمار کل درآمد (تومان)، تعداد لایسنس‌های فعال و لاگ تراکنش‌ها.
  * مدیریت لایسنس‌ها (صدور دستی، تغییر وضعیت فعال/مسدود، تمدید تاریخ انقضا، حذف).
  * امکان **ریست دستگاه‌ها (Device Reset)** در صورت تعویض گوشی کاربر.
  * مدیریت پلن‌ها و تعرفه‌های فروش.
* **بدون نیاز به تنظیمات پیچیده دیتابیس:** ایجاد خودکار جداول با پشتیبانی از MySQL و فال‌بک خودکار SQLite.

## 🚀 راهنمای نصب و راه‌اندازی

### الف) راه‌اندازی سرور لایسنس و درگاه پرداخت (روی هاست شخصی)

1. محتویات پوشه `license-server` را داخل هاست خود (مثلاً در ساب‌دامین `license.yourdomain.com` یا پوشه دلخواه) آپلود کنید.
2. فایل `license-server/config.php` را ویرایش کرده و اطلاعات زیر را وارد نمایید:
   ```php
   // مشخصات دیتابیس MySQL (در صورت خالی بودن خودکار با SQLite کار می‌کند)
   define('DB_HOST', 'localhost');
   define('DB_NAME', 'نام_دیتابیس');
   define('DB_USER', 'کاربر_دیتابیس');
   define('DB_PASS', 'رمز_دیتابیس');

   // مرچنت کد درگاه زیبال
   define('ZIBAL_MERCHANT', 'zibal'); // برای تست zibal و برای فروش واقعی مرچنت اختصاصی خود
   define('ZIBAL_CALLBACK_URL', 'https://yourdomain.com/license-server/callback.php');

   // کلمه عبور ورود به پنل مدیریت
   define('ADMIN_PASSWORD', 'admin123456');

   // لینک دانلود فایل APK اپلیکیشن
   define('APP_DOWNLOAD_URL', 'https://yourdomain.com/downloads/woocommerce-admin.apk');
   ```
3. وارد آدرس سایت خود شوید؛ جداول دیتابیس و پلن‌های پیش‌فرض به‌صورت خودکار ایجاد می‌شوند.
4. برای ورود به پنل مدیریت، به آدرس `https://yourdomain.com/license-server/admin/login.php` مراجعه کنید.

---

### ب) اجرای اپلیکیشن موبایل (React Native / Expo)

1. در فایل `src/services/licenseService.ts` آدرس سرور لایسنس خود را قرار دهید:
   ```typescript
   export const LICENSE_SERVER_URL = 'https://license.yourdomain.com';
   ```
2. پکیج‌ها را نصب کنید:
   ```bash
   npm install
   ```
3. پروژه را اجرا کنید:
   ```bash
   npx expo start
   ```
4. با برنامه **Expo Go** کد QR را اسکن کنید یا با دستور زیر خروجی APK بگیرید:
   ```bash
   npx eas build -p android --profile preview
   ```
