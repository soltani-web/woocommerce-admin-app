# اپلیکیشن موبایل مدیریت فروشگاه ووکامرس (چندفروشگاهی / Multi-Store)

یک اپلیکیشن موبایل مدرن و سبک پیاده‌سازی شده با **React Native (Expo)** و **TypeScript** با رابط کاربری کاملاً **فارسی و راست‌چین (RTL)** جهت مدیریت سفارشات، محصولات، انبار و مشتریان با اتصال مستقیم به **WooCommerce REST API**.

---

## ✨ امکانات اصلی

1. **مدیریت چندفروشگاهی (Multi-Store):**
   * امکان افزودن بینهایت فروشگاه وردپرسی با آدرس سایت، Consumer Key و Consumer Secret.
   * امکان سوییچ آنی بین فروشگاه‌ها بدون خروج از برنامه.
   * ذخیره‌سازی ایمن و محلی کلیدهای دسترسی روی دستگاه کاربر.

2. **پیشخوان و داشبورد تحلیلی:**
   * نمایش مجموع فروش ۳۰ روز اخیر و سود خالص.
   * کارت‌های آمار سفارشات در انتظار پرداخت، در حال انجام، کالاهای ناموجود و اقلام فروخته‌شده.
   * لیست آخرین سفارشات با نمایش جزئیات.

3. **مدیریت سفارش‌ها:**
   * لیست سفارشات با امکان جستجو بر اساس شماره سفارش، نام مشتری و شماره موبایل.
   * تب‌های فیلتر وضعیت (همه، در حال انجام، در انتظار پرداخت، تکمیل‌شده، لغو شده و...).
   * صفحه جزئیات کامل سفارش (اقلام، آدرس تحویل، هزینه ارسال و مالیات).
   * امکان تغییر وضعیت سفارش با یک کلیک.
   * امکان ثبت یادداشت اختصاصی برای سفارش.
   * دکمه تماس مستقیم با شماره موبایل مشتری.

4. **مدیریت محصولات و انبار:**
   * لیست محصولات به همراه تصویر، دسته‌بندی و وضعیت موجودی.
   * پنجره ویرایش سریع (Quick Edit) برای تغییر قیمت عادی، قیمت حراج و تعداد موجودی انبار بدون نیاز به باز کردن وردپرس.
   * قابلیت جستجوی کالا و کد SKU.

5. **مدیریت مشتریان:**
   * لیست مشتریان به همراه مجموع خریدهای ثبت شده و تعداد سفارش‌ها.
   * تماس مستقیم تلفنی با مشتری از داخل اپلیکیشن.

6. **تنظیمات و تست اتصال:**
   * امکان تست پایداری و سلامت اتصال REST API ووکامرس.

## 📱 نحوه اجرا روی گوشی یا شبیه‌ساز

برای اجرای برنامه روی گوشی تلفن همراه خود:

1. وارد پوشه پروژه شوید:
   `ash
   cd woocommerce-admin-app
   `

2. سرور توسعه Expo را اجرا کنید:
   `ash
   npx expo start
   `

3. **اجرا روی گوشی:**
   * اپلیکیشن **Expo Go** را از گوگل‌پلی (برای اندروید) یا اپ‌استور (برای آیفون) دانلود و نصب کنید.
   * دوربین یا اسکنر برنامه Expo Go را باز کرده و **QR Code** نمایش داده شده در ترمینال را اسکن کنید تا اپلیکیشن بلافاصله روی گوشی شما اجرا شود.

---

## 🔑 نحوه ساخت کلیدهای REST API در ووکامرس

1. وارد پیشخوان وردپرس سایت خود شوید.
2. به مسیر **ووکامرس > پیکربندی > پیشرفته > REST API** بروید.
3. روی **افزودن کلید (Add key)** کلیک کنید.
4. سطح دسترسی (Permissions) را روی **خواندن/نوشتن (Read/Write)** بگذارید.
5. کلیدهای ساخته‌شده (Consumer Key و Consumer Secret) را در اپلیکیشن وارد نمایید.
